# Activity 05 — Alignment Sensitivity Analysis

## Goal

Test whether the multiple-sequence alignment is robust to reasonable changes in alignment method and parameters.

Instead of assuming that one MAFFT command gives the uniquely correct alignment, we will generate several plausible MAFFT alignments by perturbing alignment parameters. We will also generate one independent **MUSCLE 5** alignment.

All candidate alignments are then evaluated with the same scoring framework.

The objective is not to find a magical numerical score. It is to identify whether positional homology is stable or sensitive to reasonable methodological choices.

---

## 1. Move to the alignment directory

```bash
cd /projects/LaboratoireRDP/Deep_Phylogeny_Workshop_2026/participants/$USER/03_alignment
```

The input used below is:

```text
domain_sequences.fasta
```

If you are analysing full-length proteins instead, replace this filename with your curated full-length FASTA.

---

## 2. Generate perturbed MAFFT alignments and a MUSCLE comparison

Run:

```bash
mafft_perturb \
    domain_sequences.fasta \
    --level light \
    --threads 1 \
    --parallel-jobs 2 \
    --muscle
```

For the workshop we use the **light** parameter screen to keep the analysis fast enough for an interactive session.

The program generates several MAFFT alignments by varying reasonable MAFFT parameters. MUSCLE 5 is then run once as an independent comparison and appended after the MAFFT candidates.

The exact number of candidates can depend on the screening mode and future versions of the workflow. Do not assume that MUSCLE always has a fixed alignment number.

---

## 3. Inspect the generated files

For `domain_sequences.fasta`, the output directory is:

```text
mafft_results_domain_sequences/
```

Inspect it:

```bash
ls -lh mafft_results_domain_sequences
```

Important files include:

```text
alignment_1.fasta
alignment_2.fasta
...
alignment_sources.tsv
mafft_commands.txt
mafft_generation_summary.txt
debug_logs.txt
```

`alignment_sources.tsv` records the provenance of every candidate alignment.

View it with:

```bash
cat mafft_results_domain_sequences/alignment_sources.tsv
```

This tells you which `alignment_N.fasta` files were produced by MAFFT, which MAFFT parameters were used, and which alignment was produced by MUSCLE 5.

---

## 4. Score all candidate alignments

Run:

```bash
score_alignments \
    mafft_results_domain_sequences \
    --processes 4
```

The scorer evaluates all `alignment_*.fasta` files in the directory using the same set of metrics.

The analysis includes complementary measures derived from Jalview-style conservation/quality calculations, substitution-matrix scores, entropy, gap structure, conservation, and pairwise identity.

The scorer then compares the candidate alignments using several ranking approaches.

---

## 5. Inspect the scoring report

The main output is:

```text
mafft_results_domain_sequences/alignment_scores_JALVIEW_pyMSA_v3.txt
```

Open it with:

```bash
less mafft_results_domain_sequences/alignment_scores_JALVIEW_pyMSA_v3.txt
```

or:

```bash
cat mafft_results_domain_sequences/alignment_scores_JALVIEW_pyMSA_v3.txt
```

The report contains:

- the metrics calculated for each candidate alignment;
- rankings based on BLOSUM62-oriented metrics;
- rankings based on PAM250-oriented metrics;
- an experimental combined ranking;
- agreement or disagreement among ranking approaches;
- a full score table for all alignments.

The scorer also writes:

```text
per_position_scores.txt
```

with position-specific conservation and quality information.

---

## 6. Interpret the result biologically

Do not select an alignment only because one number is slightly larger.

Ask:

- Do several scoring approaches favor the same alignment?
- Are the best-scoring candidates generated by similar or very different MAFFT parameters?
- Does MUSCLE agree with the best MAFFT candidates?
- Are several candidate alignments effectively equivalent?
- Are disagreements restricted to poorly conserved or insertion-rich regions?
- Does the preferred alignment remain biologically plausible in Jalview?

If several reasonable methods converge on essentially the same alignment, positional homology is relatively stable.

If the candidate alignments differ strongly, that uncertainty should be considered before interpreting the phylogenetic tree.

---

## 7. Inspect the selected candidate in Jalview

Use `alignment_sources.tsv` and the scoring report to identify the candidate(s) worth inspecting.

For example:

```bash
jalview mafft_results_domain_sequences/alignment_7.fasta &
```

Replace `alignment_7.fasta` with the candidate you actually want to inspect.

If two or more candidates are close in the ranking but differ in biologically important regions, inspect all of them rather than forcing an arbitrary choice.

---

## Important note about exact ties

On very simple or artificial datasets, different MAFFT parameter combinations — and even different alignment programs — can produce exactly the same positional alignment.

In that situation, a ranking has no biological meaning because there is no alignment difference to rank.

Real datasets are normally more informative, but the scoring output should always be interpreted together with the alignment itself.

---

## Key point

**Alignment uncertainty is part of phylogenetic uncertainty.**

The purpose of this activity is not merely to optimize an alignment score. It is to determine whether the evolutionary conclusions are likely to depend strongly on the alignment procedure.

Once the alignment has been evaluated and inspected, the selected alignment can be used for phylogenetic inference with IQ-TREE.
